SOFT PICK UP — SITE PRONTO PARA PUBLICAR

Ficheiros:
- index.html  -> página principal
- style.css   -> design e responsividade
- script.js   -> menu, formulário e WhatsApp

ANTES DE PUBLICAR:
1. Abra script.js.
2. Procure WHATSAPP_NUMBER.
3. Troque 258XXXXXXXXX pelo número real da Soft Pick Up, sem +, espaços ou símbolos.
4. Se quiser, altere o e-mail e os dados de contacto diretamente em index.html.
5. Abra index.html no navegador para testar.

PUBLICAÇÃO:
Pode enviar os 3 ficheiros para qualquer serviço de hospedagem de sites que aceite HTML/CSS/JS. Não é necessário servidor para a versão atual.

NOTA:
O formulário funciona através do WhatsApp e não grava dados numa base de dados.
